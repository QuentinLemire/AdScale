# 🚀 AdScale

AdScale est une application web permettant de visualiser, analyser et piloter des campagnes publicitaires (Meta Ads) via un dashboard moderne, clair et orienté performance.

---

## 🎯 Objectif du projet

L’objectif d’AdScale est de simplifier la lecture des données marketing pour permettre une prise de décision rapide :

- Comprendre ses performances en un coup d’œil
- Identifier les campagnes rentables
- Optimiser les budgets publicitaires
- Détecter les problèmes (CPC élevé, CTR faible…)

---

## 🖥️ Fonctionnalités

### 📊 Dashboard
- KPIs globaux :
  - Spend (dépenses)
  - Revenue (chiffre d’affaires)
  - Conversions
  - ROAS
  - CTR / CPC / CPM
- Graphiques d’évolution
- Répartition du budget (pie chart)
- Tableau des campagnes
- Score de performance + tendance

---

### 📢 Gestion des campagnes
- Affichage sous forme de cartes modernes
- Informations clés :
  - Budget
  - Spend
  - ROAS
  - Score
- Actions disponibles :
  - Modifier le budget
  - Activer / mettre en pause
- Recommandations automatiques
- Alertes (CPC élevé, CTR faible…)

---

### ⚙️ Paramètres
- Informations du compte
- Préférences d’affichage
- Simulation de connexion Meta Ads (prévue)

---
